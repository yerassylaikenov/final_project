# Гипотеза (записана до прогонов, 11.11.2026)

Отказ варианта 5: `FAULT='{"unavailable": true}'` — dep-a (диспетчер) отвечает 503 с 30-й по 60-ю секунду из 120.

| Прогон | Предсказание |
|---|---|
| PATTERN=off | каждый запрос идёт в dep-a → все запросы в окне 30 с падают: POFOD ≈ 30/120 = 0,25, 1 эпизод, AVAIL ≈ 0,75 |
| PATTERN=on | ответ из плана в памяти: POFOD < 1 %, AVAIL = 1,0, p95 < 50 мс |
| PATTERN=on, PLAN_MAX_AGE_S=10 | 10 с отказа — `static`, оставшиеся 20 с — failsafe 503: POFOD ≈ 20·20/2400 ≈ 0,167 |
| PATTERN=on, PLAN_MAX_AGE_S=120 | граница не достигается: POFOD ≈ 0 |
| PATTERN=on, FAULT `{"delay_ms": 2000}` | ответы из памяти; медленный только запрос, который обновляет план (≤ DEP_TIMEOUT_ON_S = 0,3 с); POFOD ≈ 0 |
